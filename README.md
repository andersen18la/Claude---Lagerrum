# Lejere på gården

`lejeroversigt.html` er et register over gårdens lejere:

- **Type:** lagerrum eller standplads med campingvogn
- **Sted:** Hus 1 (glashuset ved kontoret), Hus 11, 13, 14, 15 eller det udendørs areal
- **Startdato**, telefon, rum/plads nr., månedlig leje, note og evt. ophørsdato

Øverst vises antal aktive lejere pr. hus; klik et hus for at filtrere registret.
Registret kan søges, sorteres og hentes som CSV (åbner i Excel).

Den udgivne version gemmer data sikkert på claude.ai. Åbnes filen direkte i en
browser, gemmes data kun i den browser (localStorage) – tag jævnligt en CSV-kopi.

Stederne rettes i listen `SITES` øverst i scriptet.
